# Plan de Caramelo jugable

Diseño aprobado por el usuario el 2026-09-20: Jev evalúa, otro modelo redacta;
final ASCII dentro del boliche; preparación de beta pública.

1. [Diálogo y jugabilidad](2026-09-20-01-dialogo.md): cuatro tareas.
2. [Final ASCII](2026-09-20-02-final-ascii.md): tres tareas.
3. [Beta pública](2026-09-20-03-beta.md): tres tareas.

Fuente común: [especificación](../specs/2026-09-20-caramelo-design.md).

Orden recomendado: 01 → 02 → 03. Son diez tareas con pruebas y commits propios.
No se ejecutó la implementación durante la planificación.

Entradas externas necesarias durante ejecución: proveedor y credencial del modelo
redactor, presupuesto de evaluación y monto diario público, y destino de despliegue.
La falta de credencial no bloquea reglas, pruebas simuladas ni el final visual;
sí impide declarar validada la conversación real.

La evaluación editorial y las pruebas en teléfonos físicos no se sustituyen por
pruebas unitarias. Ni costos ni p95 se publican como medidos antes de ejecutar.
